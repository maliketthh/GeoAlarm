# Гео-будильник (GeoAlarm)

Приложение для Android, реализующее «умный» будильник, который можно выключить только физически переместившись в заданную географическую зону.

## Возможности

- 🗺️ Выбор места на карте (Яндекс.Карты)
- 📍 Автоматическое определение текущего местоположения
- ⏰ Установка времени будильника
- 🔔 Будильник срабатывает в назначенное время
- 🚶‍♂️ Выключение при входе или выходе из геозоны (радиус 20 м)
- 📊 Отслеживание пройденного расстояния и максимальной скорости
- 🟢 Визуализация пройденного пути на карте
- 🔴 Экстренное отключение (3 нажатия на кнопку)

## Технологии

- **Язык:** Kotlin
- **Карты:** Яндекс.Карты (MapKit) — отображение карты, маркеры
- **Геолокация:** Google Play Services Location (`FusedLocationProviderClient`)
- **Будильник:** AlarmManager + BroadcastReceiver
- **Звук:** MediaPlayer, Foreground Service
- **Минимальная версия:** Android 8.0 (API 26)

## Архитектура

Приложение построено на следующих компонентах:

| Компонент | Ответственность |
|-----------|------------------|
| `MainActivity` | Выбор времени и места, установка будильника |
| `ChooseLocationActivity` | Карта для выбора точки |
| `AlarmReceiver` | Приём сигнала будильника, запуск сервисов |
| `AlarmSoundService` | Воспроизведение звука и вибрации |
| `GeoAlarmActivity` | Отслеживание GPS, логика входа/выхода, статистика |
| `AlarmData` | Контейнер данных будильника |

## Установка и запуск

### Требования

- Android Studio Hedgehog | 2023.1.1+
- Android SDK 26+
- Устройство с Android 8.0+ или эмулятор

### Шаги для запуска

1. **Клонируй репозиторий:**
   ```bash
   git clone https://github.com/maliketthh/geoalarm.git
Открой проект в Android Studio:
File → Open → выбери папку проекта
Получи API-ключ Яндекс.Карт:
Зайди на https://developer.tech.yandex.ru
Авторизуйся через Яндекс ID
Выбери MapKit Mobile SDK
Создай новый ключ
В поле "Ограничение по идентификаторам приложений" укажи: com.example.geoalarm
Скопируй полученный ключ

Вставь API-ключ в проект:
Открой MyApplication.kt
Замени YOUR_API_KEY на свой ключ:
MapKitFactory.setApiKey("твой_ключ_сюда")

Подключи устройство или запусти эмулятор:
Включи отладку по USB на телефоне
Или создай эмулятор с API 26+ (Android 8.0)
Разрешения
Приложение запросит следующие разрешения:

📍 Доступ к геолокации (GPS) — нужно для отслеживания местоположения

🔔 Доступ к уведомлениям — для показа уведомления при срабатывании

⏰ Доступ к точным будильникам (Android 12+)

Использование
1. Выбор места на карте
На главном экране нажми "Выбрать место на карте"

Нажми на любую точку карты или найди адрес через поиск

Нажми "Подтвердить"

2. Установка будильника
Выбери время на TimePicker

Нажми "Установить гео-будильник"

3. Когда будильник сработает
Откроется экран с картой

На карте будет:

🟢 Зелёные точки — твой пройденный путь

🔴 Красный маркер "ЦЕНТР ЗОНЫ"

🔵 Синий маркер "ТЫ ЗДЕСЬ"

Показывается расстояние до зоны, пройденная дистанция и скорость

4. Как выключить будильник
Вариант 1: Войти в зону (радиус 20 м от выбранной точки)

Вариант 2: Выйти из зоны (если ты внутри)

Вариант 3: Нажать 3 раза на красную кнопку "Экстренное отключение"
