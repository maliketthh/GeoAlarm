# Гео-будильник (GeoAlarm)

Приложение для Android, реализующее «умный» будильник, который можно выключить только физически переместившись в заданную географическую зону.

## Возможности

- 🗺️ Выбор места на карте (Яндекс.Карты)
- 📍 Автоматическое определение текущего местоположения
- ⏰ Установка времени будильника
- 🔔 Будильник срабатывает в назначенное время
- 🚶‍♂️ Выключение при входе или выходе из геозоны (радиус 20 м)
- 📊 Отслеживание пройденного расстояния и максимальной скорости
- 🟢 Визуализация пройденного пути на карте
- 🔴 Экстренное отключение (3 нажатия на кнопку)

## Технологии

- **Язык:** Kotlin
- **Карты:** Яндекс.Карты (MapKit) — отображение карты, маркеры
- **Геолокация:** Google Play Services Location (`FusedLocationProviderClient`)
- **Будильник:** AlarmManager + BroadcastReceiver
- **Звук:** MediaPlayer, Foreground Service
- **Минимальная версия:** Android 8.0 (API 26)

## Архитектура

Приложение построено на следующих компонентах:

| Компонент | Ответственность |
|-----------|------------------|
| `MainActivity` | Выбор времени и места, установка будильника |
| `ChooseLocationActivity` | Карта для выбора точки |
| `AlarmReceiver` | Приём сигнала будильника, запуск сервисов |
| `AlarmSoundService` | Воспроизведение звука и вибрации |
| `GeoAlarmActivity` | Отслеживание GPS, логика входа/выхода, статистика |
| `AlarmData` | Контейнер данных будильника |
